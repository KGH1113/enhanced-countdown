# Contributing to Enhanced Countdown

Contributions that improve Enhanced Countdown are welcome. This is a source-available proprietary project, not an
open-source project.

## Before submitting

1. Read `LICENSE.md` and `CONTRIBUTOR_AGREEMENT.md`.
2. Create a focused fork or branch solely to prepare the contribution.
3. Keep third-party code and assets out of the contribution unless their license is disclosed and compatible.
4. Build with `./scripts/run.sh build` and run `./scripts/run.sh check`.

## Contributor Agreement

A pull request is eligible for review only when the contributor affirmatively accepts
`CONTRIBUTOR_AGREEMENT.md` in the pull request checklist. If accepted into the Project, transferable copyright
property rights in the contribution are assigned to the Project Owner as described in that Agreement.

Submitting a contribution does not authorize publishing or distributing a separate build, fork, or derivative
project.
